# SIP NAT handling implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Learn the endpoint's translated SIP address and process remote termination through a NATed VPN without changing the network.

**Architecture:** A small tracked patch to the pinned libre SDK learns numeric UDP mappings from successful, transaction-matched REGISTER responses. SIP Contact/Via serialization uses the mapping scoped to the actual local socket and registrar peer; real socket addresses, RTP binding and remote dialog targets are preserved. Build from a separate patched source tree and verify exact patch identity in the SDK manifest.

**Tech Stack:** Existing Rust adapter, C11 libre/baresip, Bun build orchestration and Docker/Asterisk fixtures. No dependency or frontend DTO changes.

**Spec:** The user explicitly requests client-side NAT handling and regression coverage, with no network changes. Existing diagnostics establish translated traffic, a local-address Contact, working media and missing remote termination. Telephone's source supplies a behavioral reference only; no Telephone/PJSIP code is imported.

## Global constraints

- Preserve existing checkout and unrelated changes; no production network/PBX changes.
- Keep C/unsafe in the native adapter and statically linked SDK; no second SIP/audio stack.
- Learn only UDP, matching peer/local socket, Call-ID/CSeq and valid numeric Via received/rport from successful registration; reject invalid/unicast/family/port data.
- Bound mappings and registration retries. Never rewrite the remote PBX Contact or media addresses.
- Remove a superseded local Contact when re-registering after learning; retain actual registration local address for RTP.
- Native library extension functions stay inside the native boundary and are documented. Frontend command/DTO contracts remain unchanged.

## Review focus

- Spoofed, failed, mismatched or malformed registration responses must not change the mapping.
- Multiple accounts/registrars sharing a socket must not share unrelated peer mappings.
- Learning a nonlocal address must not change RTP binding or break tone echo.
- Re-registration must converge, remove the previous Contact and avoid unbounded mapping growth.
- Existing SDKs without the exact patch must fail with a rebuild instruction.
