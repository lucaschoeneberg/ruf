## Issue drafts

Post these only after approval, after checking for existing equivalents. Suggested
label: `help wanted`; these involve platform acceptance and are not automatically
beginner programming tasks. Create labels only if they do not already exist.

### Test Windows 11 with a physical headset

Ruf targets Windows 11 x64, but compiling on Windows Server does not establish
desktop/audio acceptance. We need an observed test using the exact preview build.

Acceptance:

- Record Ruf tag/commit/installer, Windows version, PBX/version, codec, transport,
  media protection and synthetic network topology.
- Check registration, incoming/outgoing two-way audio, mute/hold, DTMF and both
  transfer paths; mark unavailable scenarios not tested.
- Check background/tray/quit, actual notifications, restart, sleep/wake,
  credential persistence, headset removal and a 30-minute test call.
- Submit a sanitized compatibility report; never attach personal call data.

Start with [the tester guide](../testing-preview.md). This is one qualification
profile, not a promise to support every Windows machine or SIP provider.

### Qualify FreeSWITCH interoperability

Current Asterisk evidence does not qualify FreeSWITCH. We need reproducible
results against an explicitly versioned, controlled FreeSWITCH setup.

Acceptance:

- Record server/app versions, target platform, topology and configuration using
  synthetic identities.
- Exercise G.711 A-law and mu-law, UDP/RTP, TCP/RTP and TLS/required SDES-SRTP.
- Verify two-way audio, both call directions, mute/hold/resume, DTMF, transfers,
  two-account identity and restart/recovery.
- Verify trusted TLS success, certificate/hostname rejection and no plaintext
  fallback for required protection.
- Report each result as passed, failed or not tested. Keep platform results separate.

Use [the supported-beta matrix](../release-checklist.md#supported-beta-qualification)
and [the compatibility form](../../.github/ISSUE_TEMPLATE/compatibility_report.yml).

### Check first-run setup on a fresh Mac

Help make [the source setup](../../README.md#run-locally) and
[the installer guide](../testing-preview.md) reproducible for a new contributor.

Acceptance:

- Record macOS version, Apple Silicon model and exact app/source revision.
- Follow the documented steps without assuming developer credentials or a running lab.
- Record actual permission prompts, empty first-run account fields, installation,
  close/reopen, explicit Quit and the first controlled two-way audio call.
- Report unclear instructions, missing dependencies and setup failures with the
  exact step and a proposed documentation correction.
- Never bypass OS protection or publish personal SIP credentials.

## Release handoff

- Version: **0.1.0**; intended tag: **v0.1.0**; title: **Ruf 0.1.0 Developer Preview**.
- Pricing: free Developer Preview, no in-app purchases. No final App Store price
  or lifetime-support commitment is established by this preview.
- Body: [0.1.0 release notes](0.1.0.md).
- State: draft + prerelease until explicitly approved for publication.
- Assets: native macOS Apple Silicon DMG and Windows x64 NSIS EXE, each matching
  its CycloneDX SBOM and build-hash manifest, plus `SHA256SUMS` for the installers.
- Source: one reviewed revision containing all intended localization/artwork
  sources. A package from an uncommitted working tree is only a local candidate.

Before tagging, complete [the existing checklist](../release-checklist.md), observe
all required hosted jobs for that revision and verify the downloaded assets.
The existing tag workflow creates only a draft prerelease, but pushing its tag
still changes the public repository and is not authorized in this preparation.
Do not manufacture a Windows package or copy a previous build into this release.

Confirm signing/notarization for each exact installer. Default direct builds are
ad-hoc signed on macOS and unsigned on Windows. A local Developer ID build is
documented separately; it does not automatically change hosted build identities
or prove notarization. Use the status of the actual asset, not a generic badge.
