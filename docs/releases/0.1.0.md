# Ruf 0.1.0 · Preview

Ruf is a compact SIP softphone for macOS 14+ on Apple Silicon and Windows 11 x64.
This preview is intended for isolated test networks: SIP/UDP and G.711 RTP are
unencrypted. One call can be active at a time. Provider compatibility and real
microphone/headset operation require testing on the installed application.

## Included

- Up to eight saved SIP accounts with independent registration and outgoing
  account selection. Passwords use macOS Keychain / Windows Credential Manager.
- Incoming/outgoing calls, answer, reject and hangup; typed registration and call
  errors, background ringing, tray controls and actionable notifications.
- Separate microphone, speaker and ringtone device settings.
- Authorized macOS contact search, favorites and direct dialing. Windows contact
  integration is not available.
- Local SQLite call history with results, duration, search and callback through
  the original account.
- About page with bundled changelog, license texts and a dependency inventory in
  CycloneDX format.

## Distribution status

macOS packages use ad-hoc signing; Windows installers are unsigned. Developer ID
signing, notarization, Windows signing and automatic updates are not configured.
TLS/SRTP and calendar integration are not implemented. The generated inventory
requires review against the shipped variant and is not a compliance attestation.

The workflow creates a draft prerelease only after quality, native build/test and
Asterisk SIP/RTP jobs pass. It attaches one DMG, one NSIS installer, the matching
SBOM/build-hash manifests and SHA256SUMS for the installers.
To verify downloaded installers in the same directory, run `sha256sum -c SHA256SUMS`
(macOS: `shasum -a 256 -c SHA256SUMS`). Checksums detect changed downloads; they do
not replace publisher signing. Hosted builds do not establish Windows runtime,
hardware audio, notification interaction or provider compatibility.
