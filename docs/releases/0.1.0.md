# Ruf 0.1.0 · Preview

Ruf is a compact SIP softphone for macOS 14+ on Apple Silicon and Windows 11 x64.
This preview is intended for isolated test networks: UDP/TCP and ordinary RTP are
unencrypted. Accounts can require TLS and SDES-SRTP with certificate/hostname
verification and no plaintext fallback. At most two related dialogs share one
audible conversation. Provider compatibility and real
microphone/headset operation require testing on the installed application.

## Included

- Up to eight saved SIP accounts with independent registration and outgoing
  account selection. Accounts can be disabled without deleting credentials or
  silently switching outgoing identity. Passwords use macOS Keychain / Windows
  Credential Manager; explicit reconnect supports credential-access recovery.
- Incoming/outgoing calls, answer, reject and hangup; typed registration and call
  errors, background ringing, tray controls and actionable notifications.
- Native mute, confirmed hold/resume, blind transfer and consultation with switching,
  cancellation and attended transfer. Unsolicited incoming REFER is rejected.
  An expandable in-call keypad sends native DTMF, including star/hash IVR input.
- Eight settings sections with concrete field search, protected drafts, keyboard
  focus, account-specific accessible action names and long-name wrapping.
- Separate microphone, speaker and ringtone routing; classic/soft/short ringtones
  and ringtone-only volume. Explicit native microphone metering runs for at most
  ten seconds, and a speaker test for two seconds. Real calls preempt audio tests.
- Independent notification, microphone and contact permission checks. OS prompts
  require explicit actions; saving the notification switch never requests access.
  Anonymous delayed test notifications and optional caller-detail hiding help
  check background notifications without creating a fake call.
- Login-only hidden-start preference; manual opening still shows the phone.
- Authorized macOS contact search, favorites and direct dialing. Windows contact
  integration is not available. Favorites-first ordering and organization labels
  are configurable.
- Formatted telephone numbers accept a leading plus and visual separators.
  Authorized contacts provide dial suggestions and current names in conversations,
  notifications and older history. German national/international number matching
  is configurable and never rewrites the dialed number.
- Local SQLite call history with results, duration, search and callback through
  the original account. Recording can be disabled for future calls while retaining
  prior rows. Completed entries can expire after 30/90/365 days; unlimited retention
  remains the default. Shortening that would delete rows requires confirmation.
- Local health diagnostics with an explicit preview/copy action and a whitelist
  excluding personal account, caller and contact details.
- About page with bundled changelog, license texts and a dependency inventory in
  CycloneDX format.

## Existing installations

Password-free account/settings metadata uses schema version 2. Existing version-1
files load with compatibility defaults; the exact original bytes are backed up
before the first replacement. Credential keys and outgoing selection remain
intact. Disabled accounts restore without reading passwords or creating native
user agents. See [preferences and migration](../api/preferences.md) and
[account activation](../api/account-activation.md).

## Verification boundaries

Local macOS verification covers UI/browser regressions, native state/audio
ownership tests, isolated Asterisk SIP/RTP scenarios, and signed bundle metadata.
A recent local installation/start check also confirmed the installed executable
matched its build and the phone window appeared. These checks do not establish
real notification banners, hardware microphone/speaker behavior, provider
compatibility or Windows runtime. See the
[settings verification](../verification/2026-11-05-settings-redesign.md) and
[audit fixes](../verification/2026-11-05-settings-audit-fixes.md), plus
[native call controls and security](../verification/2026-11-05-call-controls-security.md).

Microphone authorization metadata is currently implemented on macOS. Other
platforms report unsupported metadata; explicit microphone tests rely on native
capture succeeding. Windows contacts remain unavailable. Caller-details hiding
applies to OS notification text, not the phone window or retained history.

## Distribution status

macOS packages use ad-hoc signing; Windows installers are unsigned. Developer ID
signing, notarization, Windows signing and automatic updates are not configured.
Calendar integration is not implemented. The generated inventory
requires review against the shipped variant and is not a compliance attestation.

The workflow creates a draft prerelease only after quality, native build/test and
Asterisk SIP/RTP jobs pass. It attaches one DMG, one NSIS installer, the matching
SBOM/build-hash manifests and SHA256SUMS for the installers.
To verify downloaded installers in the same directory, run `sha256sum -c SHA256SUMS`
(macOS: `shasum -a 256 -c SHA256SUMS`). Checksums detect changed downloads; they do
not replace publisher signing. Hosted builds do not establish Windows runtime,
hardware audio, notification interaction or provider compatibility.
