# About Ruf: company attribution, links and software inventory

Implemented on macOS on 2026-11-05.

## Behavior and reused patterns

- “Über Ruf” identifies Mardu GmbH as author/developer, with the official company,
  legal-notice and website-privacy URLs. Native clicks use an enum-selected IPC
  command and the existing blocking-task/OS-application-launch pattern.
- The settings-only capability permits the new command; callers cannot provide
  arbitrary URLs. Browser previews use ordinary external links. Opening errors
  keep the About page visible and show a recovery message.
- The UI reuses the settings typography, colors, row styles and disclosures.
  LICENSE, THIRD_PARTY_NOTICES, native notices and the font license are embedded
  as selectable plain text, available offline. No project dependencies were added.
- The build reads Cargo/Bun lockfiles and native source pins through the pinned
  Bun runtime. It embeds a 587-component project SBOM and emits the same data as
  `software-bill.cdx.json`. This is a project inventory, including build tools and
  platform variants, rather than a binary-specific distribution inventory.

## Follow-up: compact layout and consumer changelog

The initial redesign was reduced after user feedback. The original “Diese Version”,
“Konten & Passwörter” and “Telefonie” rows are restored. The smaller Ruf mark sits
beside the title. Mardu attribution and company links form a small footer. Software
details start collapsed and show eight central components; the full SBOM remains a
nested JSON disclosure, without a 587-item list in the interface.

“Was ist neu?” reads a separate consumer-oriented `CHANGELOG.md` describing usable
features rather than commits. The file ships with the app. An optional public
GitHub raw URL can refresh it when opened, retaining bundled notes on network,
HTTP, parsing or timeout errors. No production GitHub source has been configured:
this checkout still has no Git remote. The API reference documents the optional
build setting, supported Markdown format, fetching and fallback behavior.
