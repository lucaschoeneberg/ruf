execution, not hosted CI or Windows execution.

- Imported the last committed npm lockfile into Bun's text lockfile in ignored
  scratch space; the user's existing deletion of `package-lock.json` was preserved.
  All 84 retained registry package resolutions match their previous versions and
  SHA-512 integrity hashes. Only the two Prettier packages were removed.

- Svelte/TypeScript checks, Vite build, application/toolchain version checks and

  for the repository without a Prettier/plugin dependency. Generated contracts
  remain excluded from formatting; the only generated DTO change is the command

  HTTP 200 probe also pass with a failing `node` launcher first on PATH, confirming

- Native SDK orchestration and the native macOS app bundle build succeed under
  Bun, including the Tauri before-build frontend command. The existing C/Rust
  ownership model, dependencies and SIP behavior were reused.

  The real two-call stale-action regression passes too. The lab is stopped after
  verification; unrelated containers remain untouched.

CI now installs pinned Bun via a commit-pinned setup action, performs frozen
installs, and uses Bun for all project JavaScript commands. Dependabot monitors
