# Frontend reliability audit — 2026-11-05

This pass inspected frontend source beyond the existing dirty diff. It preserved
the credential recovery and notification authorization changes already present.
All browser scenarios used synthetic IPC, contacts and history. No personal
address book, credentials, native audio or SIP service was accessed.

The first browser run observed the favorite failure. After fixing that bug, the
second run observed both history failures and the actual duplicate-key exception.
After the remaining fixes, the complete browser command passed all five suites.
Independent review then found the fully overlapping page case. Its new regression
failed against the first merge fix and passed after separating server progress
from the unique rendered row count.

## Limits

Offset pagination reflects a changing dataset, not a database snapshot. Overlap
no longer duplicates/crashes rows; focus/event/manual refresh continues to reload
the current loaded window. New or removed records between separate offset reads
can still appear on the next refresh, as before.

These checks establish browser/IPC behavior only. This pass did not run hosted CI,
Windows runtime tests, native desktop bundling, real OS permission dialogs,
keychain access, SIP or native audio. Workspace/native checks are tracked by the
coordinating audit.
