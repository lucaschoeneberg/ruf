# Interoperability lab

Reserved for reproducible Asterisk/FreeSWITCH configs and SIPp scenarios once the
native engine is linked. There are no executable interoperability tests yet.

Record exact engine/server versions, transport, codecs, encryption, network path
and results. Use synthetic accounts and numbers. Never commit provider passwords,
personal address books or unredacted captures. The MVP design defines the eventual
beta gate; a desktop CI build is not a substitute for those tests.
